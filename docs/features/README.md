# docs/features/

Cada feature deste projeto começa com um spec aqui antes de virar código.

## Convenção
`feature-NNN-slug.md` onde NNN é número sequencial e slug é descrição curta em kebab-case.

Status do spec: `Draft` -> `Approved` -> `In Progress` -> `Done`.

## Por que spec-first
Implementações sem spec acumulam dívida — checklist do CLAUDE.md global do orquestrador exige spec aprovado antes de código.
